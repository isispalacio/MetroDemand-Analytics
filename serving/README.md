# Consumo REST
Configure `DATABRICKS_HOST` (URL base HTTPS) y `DATABRICKS_TOKEN` como variables de entorno locales. Ejecute `python serving/predict.py` desde la raíz. Se requieren permisos de consulta del endpoint. El ejemplo de respuesta corresponde a la prueba real en la interfaz; el cliente externo no se ha probado contra el servicio. `endpoint_config.json` es una descripción reconstruida, no un export importable. El servicio recibe calendario y operación precalculados: domingo=1, lunes=2, ..., sábado=7. No recibe fechas directamente. El cero fuera de operación depende de la bandera suministrada.
