# 📊 Dashboard de MetroDemand Analytics

Visualización interactiva diseñada y publicada en Databricks a partir de las tablas analíticas del proyecto. Incluye centro de control, inteligencia de movilidad, calidad y trazabilidad, inteligencia predictiva y planificación operativa.
